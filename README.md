🎮 ARMSX2 Hybrid

A Classic Interface. A Modern Emulation Core.

ARMSX2 Hybrid is an unofficial Android PlayStation 2 emulator project that combines the familiar AetherSX2/NetherSX2 interface with the ARMSX2 emulation core.

The project aims to preserve the classic AetherSX2 experience while introducing modern features, customizable touchscreen controls, and new ways to enjoy PlayStation 2 games on Android.

Platform: Android (ARM64)

✨ Features

🚀 ARMSX2 Emulation Core

- Powered by the ARMSX2 emulation core.
- Classic AetherSX2/NetherSX2-based frontend.
- Graphics and emulator settings compatibility integration.
- Hardware and software rendering options, subject to core support.
- Performance and compatibility improvements inherited from the integrated core.

🎮 Advanced Touchscreen Controls

- Dynamic Analog: Floating virtual analog sticks for more comfortable gameplay.
- Static Analog: Traditional fixed-position analog controls.
- Custom Button Skins: Personalize the appearance of touchscreen buttons.
- Adjustable touchscreen layouts and controls.
- Multitouch input support.

🖼️ Enhanced Game Library

- Automatic game cover downloads.
- 2D and 3D cover display modes.
- Familiar game library navigation.
- Customizable visual experience.

📡 Remote Play — New!

- Remote Play integration for an expanded gaming experience.
- Designed to enable gameplay across connected devices.
- Currently under development and testing.

Remote Play capabilities, connection requirements, and availability will be documented as testing progresses.

⚙️ In-Game Features

- Quick access to emulator settings.
- Save State and Load State menu integration.
- Frame limiter controls.
- Software renderer toggle.
- Customizable on-screen controller experience.

Some settings and in-game functions may still require additional compatibility work.
